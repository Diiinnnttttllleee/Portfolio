# DPM — UX/UI Portfolio

A personal UX/UI design portfolio showcasing three self-initiated case studies:

- NaTIS Learner's License Booking — redesigning a civic booking system to reduce unfair, luck-based slot competition
- Crown & Coil — a local salon website concept focused on pricing transparency and booking clarity
- Pulse by Peloyaka — a premium e-commerce experience for an emerging headphone brand

Each project includes research, problem framing, design rationale, and honest reflection on what worked and what I'd improve.

 **Live site:** https://dpm-portfolio.netlify.app/

Built with HTML, CSS, and Figma.
